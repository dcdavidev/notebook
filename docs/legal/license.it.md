Al contrario, le nostre General Public License hanno lo scopo di garantire la libertà di condividere e modificare tutte le versioni di un programma, per assicurare che resti software libero per tutti i suoi utenti.

Quando parliamo di software libero ci riferiamo alla libertà, non al prezzo. Molti sviluppatori di software libero sono incoraggiati da questo e ne sono grati. Tuttavia, nel caso del software usato su server di rete, questo risultato può non verificarsi. La GNU General Public License permette di creare una versione modificata e di renderla accessibile al pubblico su un server, senza mai rilasciarne il codice sorgente al pubblico.

Richiede all'operatore di un server di rete di fornire il codice sorgente della versione modificata in esecuzione sul server agli utenti di quel server. Quindi l'uso pubblico di una versione modificata, su un server accessibile pubblicamente, dà al pubblico accesso al codice sorgente della versione modificata.
