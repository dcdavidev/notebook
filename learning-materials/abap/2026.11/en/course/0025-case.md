Often you compare the same variable with a list of values: if the airline is `LH` do this, if it's `AZ` do that, if it's `UA` do something else. You can write it with [IF and ELSEIF](./0024-if-and-logical-expressions.md), but you repeat the variable in every condition. `CASE` says the same thing more clearly: name the value once, then list the possible cases.

## The CASE statement

```abap
REPORT zcase_demo.

DATA lv_carrid TYPE s_carr_id VALUE 'AZ'.

CASE lv_carrid.
  WHEN 'LH'.
    WRITE / 'Lufthansa'.
  WHEN 'AZ'.
    WRITE / 'ITA Airways'.
  WHEN 'UA'.
    WRITE / 'United Airlines'.
  WHEN OTHERS.
    WRITE / 'Other airline'.
ENDCASE.
```

- After `CASE` comes the value to check, called the **operand**.
- Each `WHEN` lists a value. ABAP compares the operand with each `WHEN` from top to bottom, runs the code of the **first** match, and then continues after `ENDCASE`.
- `WHEN OTHERS` runs when no other `WHEN` matches. It's optional, but if you leave it out and nothing matches, nothing happens.

> [!TIP]
> `CASE` is like the sorting desk of a post office: the clerk reads the postcode once and drops the letter into the right box. Letters with an unknown postcode go into the "others" box.

## Several values in one WHEN

Join values with `OR` when they lead to the same code:

```abap
CASE lv_carrid.
  WHEN 'LH' OR 'AZ' OR 'AF'.
    WRITE / 'European airline'.
  WHEN 'UA' OR 'AA' OR 'DL'.
    WRITE / 'US airline'.
  WHEN OTHERS.
    WRITE / 'Other region'.
ENDCASE.
```

The values after `WHEN` can be literals, constants, or variables. Constants make the code easier to read and to change:

```abap
CONSTANTS lc_status_open   TYPE c LENGTH 1 VALUE 'O'.
CONSTANTS lc_status_closed TYPE c LENGTH 1 VALUE 'C'.

DATA lv_status TYPE c LENGTH 1 VALUE 'C'.

CASE lv_status.
  WHEN lc_status_open.
    WRITE / 'Booking open'.
  WHEN lc_status_closed.
    WRITE / 'Booking closed'.
  WHEN OTHERS.
    WRITE / 'Unknown status'.
ENDCASE.
```

## CASE or IF?

`CASE` compares with `=` only. As soon as you need anything else, use `IF`.

| Situation                                          | Use    |
| -------------------------------------------------- | ------ |
| one variable compared with a list of fixed values  | `CASE` |
| ranges (`< 10`, `BETWEEN`), `IS INITIAL`, patterns | `IF`   |
| conditions on several different variables          | `IF`   |

```abap
DATA lv_seats_free TYPE i VALUE 3.

CASE lv_seats_free.
  WHEN 0.
    WRITE / 'Sold out'.
  WHEN OTHERS.
    IF lv_seats_free < 5.          " a range: back to IF
      WRITE / 'Last seats'.
    ELSE.
      WRITE / 'Available'.
    ENDIF.
ENDCASE.
```

> [!WARNING]
> Only one branch runs. If two `WHEN` lines contain the same value, the second one is never reached, and the syntax check doesn't always tell you. Keep the values of each `WHEN` distinct.

> [!WARNING]
> Always add `WHEN OTHERS` when an unexpected value is a possible error, and handle it there, for example with a message. A silent `CASE` that skips unknown values is a common source of bugs.

When you need a value instead of a branch of statements, the expression `SWITCH` does the same job inside an assignment; you'll see it in [COND and SWITCH](./0092-cond-and-switch.md). For object types there's `CASE TYPE OF`, which belongs with [Polymorphism and casting](./0085-polymorphism-and-casting.md).

## Exercise

> [!IMPORTANT]
>
> A variable `lv_class` contains a booking class: `F` (first), `C` (business), or `Y` (economy).
>
> 1. With `CASE`, print the name of the class, and `Unknown class` for any other value.
> 2. Also set a variable `lv_luggage` to the free luggage allowance: 40 kg for `F` and `C`, 23 kg for `Y`, 0 otherwise. Print it.

### Solution

```abap
REPORT zcase_exercise.

DATA lv_class   TYPE c LENGTH 1 VALUE 'C'.
DATA lv_luggage TYPE i.

CASE lv_class.
  WHEN 'F'.
    WRITE / 'First class'.
  WHEN 'C'.
    WRITE / 'Business class'.
  WHEN 'Y'.
    WRITE / 'Economy class'.
  WHEN OTHERS.
    WRITE / 'Unknown class'.
ENDCASE.

CASE lv_class.
  WHEN 'F' OR 'C'.
    lv_luggage = 40.
  WHEN 'Y'.
    lv_luggage = 23.
  WHEN OTHERS.
    lv_luggage = 0.
ENDCASE.

WRITE: / 'Luggage (kg):', lv_luggage.
```

> [!NOTE]
>
> - `CASE operand. WHEN value. ... ENDCASE.` runs the code of the first `WHEN` that equals the operand.
> - Join several values with `OR` in a single `WHEN`.
> - `WHEN OTHERS` catches every value that no other `WHEN` matches; use it to handle unexpected values.
> - `CASE` compares only with `=`: for ranges, patterns, or several variables, use `IF`.
> - `SWITCH` is the expression form of `CASE`.
