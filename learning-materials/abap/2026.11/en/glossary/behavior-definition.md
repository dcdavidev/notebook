## Behavior definition

The RAP object that declares what a business object can do: operations, fields, validations, determinations, actions, drafts. Lesson [141](../course/0141-rap-behavior-definition.md).

## Behavior pool

The global class that holds the behavior implementation of a RAP business object. Lesson [141](../course/0141-rap-behavior-definition.md).

## Action

A non-standard operation of a RAP business object, such as "Approve", implemented in the behavior implementation. Lesson [142](../course/0142-rap-validations-determinations-actions.md).

## Determination

In RAP, logic that automatically computes some field values when the data changes. Lesson [142](../course/0142-rap-validations-determinations-actions.md).

## Validation

In RAP, a check on the data that blocks the save and returns a message if the values are not valid. Lesson [142](../course/0142-rap-validations-determinations-actions.md).

## Feature control

In RAP, the logic that enables or disables operations and fields depending on the data, for example an action available only for open orders. Lesson [143](../course/0143-eml.md).
