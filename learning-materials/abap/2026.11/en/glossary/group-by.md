## `GROUP BY`

In SQL it groups rows to compute aggregates; with `LOOP AT ... GROUP BY` it groups the rows of an internal table. Lessons [56](../course/0056-aggregates-and-group-by.md), [95](../course/0095-grouping-internal-tables.md).

## `HAVING`

The SQL condition that filters groups after `GROUP BY`, based on aggregate values. Lesson [56](../course/0056-aggregates-and-group-by.md).

## Aggregate function

An SQL function that computes one value over a group of rows: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Lesson [56](../course/0056-aggregates-and-group-by.md).
