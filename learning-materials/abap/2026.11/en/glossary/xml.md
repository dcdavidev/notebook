## XML

The markup format for data exchange; in ABAP you read and build it with `CALL TRANSFORMATION` and the iXML library. Lesson [127](../course/0127-json-and-xml.md).

## `CALL TRANSFORMATION`

The statement that converts ABAP data to XML or JSON and back, with the `ID` transformation or a _Simple Transformation_. Lesson [127](../course/0127-json-and-xml.md).
