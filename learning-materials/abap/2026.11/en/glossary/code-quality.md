## ATC (ABAP Test Cockpit)

The tool that runs static checks on code: errors, performance, security, and style rules. Lesson [107](../course/0107-code-quality.md).

## Code Inspector (SCI)

The tool that runs configurable static checks on code; its checks also run inside ATC. Lesson [107](../course/0107-code-quality.md).
