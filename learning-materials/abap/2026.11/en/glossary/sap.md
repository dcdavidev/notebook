## SAP

The German company that makes ERP business software, such as SAP ECC and SAP S/4HANA, that many companies run on. Lesson [1](../course/0001-what-is-sap.md).

## SAP GUI

The desktop program the user installs to log on to the SAP system and use transactions. Lesson [5](../course/0005-sap-gui-and-transaction-codes.md).

## SAP HANA

SAP's in-memory, column-store database, on which SAP S/4HANA and code pushdown run. Lesson [131](../course/0131-code-pushdown.md).

## SAP S/4HANA

SAP's current ERP, which runs only on SAP HANA and uses CDS, Fiori, and ABAP Cloud; it replaced SAP ECC. Lesson [1](../course/0001-what-is-sap.md).
