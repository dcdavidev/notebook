## Event

A signal an object raises with `RAISE EVENT` that other objects respond to with handler methods registered with `SET HANDLER`. Lesson [86](../course/0086-events.md).

## `SET HANDLER`

The statement that registers a handler method for an event, so the method is called every time the event is raised. Lesson [86](../course/0086-events.md).
