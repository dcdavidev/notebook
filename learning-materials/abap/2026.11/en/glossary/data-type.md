## Character types

The types for text: `c` with fixed length, `n` for numeric text, `string` with variable length. Lesson [13](../course/0013-character-types.md).

## Numeric types

The types for numbers: `i` and `int8` integers, `p` packed with fixed decimals, `decfloat16` and `decfloat34`, `f` binary floating point. Lesson [14](../course/0014-numeric-types.md).

## Date and time types

The types `d` (date, `YYYYMMDD`), `t` (time, `HHMMSS`), `utclong`, and time stamps, which support calculations. Lesson [15](../course/0015-date-and-time-types.md).

## `TYPES`

The statement that defines a local data type, to use later with `TYPE`. Lesson [17](../course/0017-types-and-like.md).

## `LIKE`

The addition that declares a data object with the same type as another existing data object. Lesson [17](../course/0017-types-and-like.md).

## Type conversion

Turning a value of one type into another, either automatically by the conversion rules or explicitly with `CONV` and `EXACT`. Lesson [19](../course/0019-type-conversions.md).
