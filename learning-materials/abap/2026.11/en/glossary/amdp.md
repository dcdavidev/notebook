## ABAP Managed Database Procedure (AMDP)

An ABAP method whose code is written in SQLScript and runs directly in the SAP HANA database. Lesson [137](../course/0137-amdp.md).

## SQLScript

The procedural language of SAP HANA in which AMDP methods and CDS table functions are written. Lessons [137](../course/0137-amdp.md), [138](../course/0138-cds-table-functions.md).
