## Data reference

A `REF TO` variable that holds the address of a data object and is dereferenced with `->*`. Lesson [42](../course/0042-data-references.md).

## `CREATE DATA`

The statement that creates an anonymous data object at runtime, even with a type decided only during execution. Lessons [42](../course/0042-data-references.md), [116](../course/0116-dynamic-data.md).
