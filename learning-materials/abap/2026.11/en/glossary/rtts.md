## RTTS (Runtime Type Services)

The classes that describe a type at runtime (RTTI) and create new ones (RTTC), such as `CL_ABAP_TYPEDESCR`. Lesson [115](../course/0115-rtts.md).

## RTTI, RTTC

The two parts of RTTS: _Runtime Type Identification_ reads a type's description, _Runtime Type Creation_ builds a new type at runtime. Lesson [115](../course/0115-rtts.md).
