## ABAP

The programming language of SAP systems: it runs on the application server and is used to build reports, interfaces, extensions, and services. Lesson [2](../course/0002-what-is-abap.md).

## ABAP Development Tools (ADT)

The Eclipse-based IDE for ABAP; it is the only tool for CDS, RAP, and ABAP Cloud. Lesson [6](../course/0006-abap-development-tools.md).

## Pretty printer

The editor feature that reformats code: indentation and upper or lower case for keywords. Lesson [10](../course/0010-comments-and-formatting.md).
