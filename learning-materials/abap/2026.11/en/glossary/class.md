## Class

The blueprint objects are created from: it defines attributes, methods, and events. It can be local (inside a program) or global (in the repository). Lessons [76](../course/0076-classes-and-objects.md), [87](../course/0087-global-classes.md).

## Abstract class

A class declared `ABSTRACT` that cannot be instantiated: it exists only as a superclass. Lesson [83](../course/0083-abstract-and-final.md).

## Final class

A class declared `FINAL` that cannot be inherited from. Lesson [83](../course/0083-abstract-and-final.md).

## Global class

A class stored in the repository (transaction SE24 or ADT) that every program can use. Lesson [87](../course/0087-global-classes.md).

## Local class

A class defined inside a program, visible only in that program. Lesson [76](../course/0076-classes-and-objects.md).

## Static component

A class attribute or method (`CLASS-DATA`, `CLASS-METHODS`) shared by all instances and used without creating an object. Lesson [81](../course/0081-static-components.md).
