## Service definition

The RAP object that lists the CDS entities a service exposes. Lesson [144](../course/0144-rap-business-services.md).

## Service binding

The RAP object that publishes a service definition with a protocol, such as OData V2 or V4, for UI or API use. Lesson [144](../course/0144-rap-business-services.md).
