## Object

An instance of a class, with its own attribute values, reached through a reference variable. Lesson [76](../course/0076-classes-and-objects.md).

## Instance

A concrete object created from a class with `NEW` or `CREATE OBJECT`, with its own attribute values. Lesson [76](../course/0076-classes-and-objects.md).

## Reference variable

A variable `TYPE REF TO` a class or interface that points to an object; several variables can point to the same object. Lesson [76](../course/0076-classes-and-objects.md).

## Garbage collector

The runtime mechanism that frees the memory of objects that no reference variable points to any more. Lesson [76](../course/0076-classes-and-objects.md).
