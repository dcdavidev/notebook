## Foreign key

The link between a table field and the key of a check table, which the Dictionary uses to validate the values entered. Lesson [47](../course/0047-foreign-keys-and-check-tables.md).

## Check table

The table that holds the allowed values of a field, linked through a foreign key. Lesson [47](../course/0047-foreign-keys-and-check-tables.md).
