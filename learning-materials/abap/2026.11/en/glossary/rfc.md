## RFC (Remote Function Call)

Calling a function module on another system, synchronously or asynchronously, through a destination (SM59). Lesson [124](../course/0124-rfc.md).

## RFC destination

The configuration (transaction SM59) that tells an RFC or an HTTP client where the other system is and how to connect. Lessons [124](../course/0124-rfc.md), [126](../course/0126-http-and-rest.md).
