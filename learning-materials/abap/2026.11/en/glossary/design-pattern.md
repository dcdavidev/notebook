## Design pattern

A proven solution to a recurring design problem: singleton, factory, strategy, observer, and others. Lesson [88](../course/0088-design-patterns.md).

## Singleton

The design pattern that guarantees a single instance of a class, created by a static method such as `get_instance( )`. Lesson [88](../course/0088-design-patterns.md).

## Factory

The design pattern in which a method creates objects for the caller and decides which class to instantiate. Lesson [88](../course/0088-design-patterns.md).
