## Exception

An error situation that interrupts the normal flow and is handled with `TRY ... CATCH ... ENDTRY`. Lesson [89](../course/0089-class-based-exceptions.md).

## Exception class

A class inheriting from `CX_STATIC_CHECK`, `CX_DYNAMIC_CHECK`, or `CX_NO_CHECK` that represents an error; raised with `RAISE EXCEPTION`. Lessons [89](../course/0089-class-based-exceptions.md), [90](../course/0090-custom-exception-classes.md).
