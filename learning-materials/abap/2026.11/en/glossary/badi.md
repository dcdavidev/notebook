## BAdI (Business Add-In)

An object-oriented extension point provided by SAP: you implement an interface to add logic to the standard without modifying it. Lesson [122](../course/0122-badis.md).

## Enhancement spot

The container that holds related BAdIs and enhancement points, to which the implementations are attached. Lessons [122](../course/0122-badis.md), [123](../course/0123-enhancement-points.md).
