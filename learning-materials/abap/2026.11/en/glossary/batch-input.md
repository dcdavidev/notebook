## Batch input

The technique that loads data by simulating manual input on a transaction's screens (`CALL TRANSACTION`, SM35). Lesson [130](../course/0130-batch-input.md).

## `CALL TRANSACTION`

The statement that starts a transaction from a program; with `USING` it runs the screens of a batch input right away. Lesson [130](../course/0130-batch-input.md).

## Batch input session

A set of transactions to run, stored in the system, processed and monitored with SM35. Lesson [130](../course/0130-batch-input.md).
