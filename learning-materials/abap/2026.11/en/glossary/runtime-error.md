## Runtime error

An error that occurs while the program runs, such as a division by zero, and produces a dump if not handled. Lesson [30](../course/0030-runtime-errors.md).

## Short dump

The common name of a runtime error that stops the program; analyzed with transaction ST22. Lesson [30](../course/0030-runtime-errors.md).
