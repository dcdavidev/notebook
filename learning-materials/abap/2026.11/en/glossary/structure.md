## Structure

A data object made of several fields (components) of different types, like a table row. Lessons [31](../course/0031-structures.md), [48](../course/0048-ddic-structures-and-table-types.md).

## Nested structure

A structure that contains other structures or tables as components. Lesson [32](../course/0032-nested-structures.md).

## Include structure

A Dictionary structure embedded in another structure or table with `.INCLUDE`, so its fields are reused in several places. Lesson [32](../course/0032-nested-structures.md).
