## User exit

An old extension point: an empty subroutine in standard code (often `USEREXIT_*`) where the customer adds their own code. Lesson [121](../course/0121-user-exits-and-customer-exits.md).

## Customer exit

An older extension point provided by SAP (`EXIT_*` function modules, managed with CMOD and SMOD). Lesson [121](../course/0121-user-exits-and-customer-exits.md).
