## Domain

The Dictionary object that defines the technical attributes of a field: type, length, allowed values. Lesson [44](../course/0044-domains.md).

## Value table

The table named in a domain as the source of the allowed values, proposed as the check table for foreign keys. Lessons [44](../course/0044-domains.md), [47](../course/0047-foreign-keys-and-check-tables.md).
