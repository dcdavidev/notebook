## `IF`

The statement that runs a block of code only if a logical expression is true, with optional `ELSEIF` and `ELSE`. Lesson [24](../course/0024-if-and-logical-expressions.md).

## `CASE`

The statement that picks a branch by comparing one value with a list of `WHEN` alternatives. Lesson [25](../course/0025-case.md).

## `COND`

A constructor expression that returns a value chosen among several `WHEN` conditions, like an `IF` in a single expression. Lesson [92](../course/0092-cond-and-switch.md).

## `SWITCH`

The expression that returns a value based on the value of one operand, like a `CASE` in a single expression. Lesson [92](../course/0092-cond-and-switch.md).
