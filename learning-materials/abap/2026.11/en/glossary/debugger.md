## Debugger

The tool that runs a program step by step and shows the values of its variables. Lesson [28](../course/0028-debugger-basics.md).

## Breakpoint

A point in the code where the debugger stops execution; it can be a session, external, or user breakpoint. Lesson [29](../course/0029-breakpoints-and-watchpoints.md).

## Watchpoint

A debugger stop that fires when a variable's value changes or meets a condition. Lesson [29](../course/0029-breakpoints-and-watchpoints.md).
