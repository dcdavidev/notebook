## Database table

A table defined in the Dictionary and created in the database (transparent table), with fields, a key, and technical settings. Lesson [46](../course/0046-database-tables.md).

## Transparent table

A Dictionary table that matches a physical table in the database, with the same fields. Lesson [46](../course/0046-database-tables.md).

## Table buffering

A copy of a table, or part of it, in the application server's memory, for reading without going to the database. Lesson [46](../course/0046-database-tables.md).

## `INSERT`, `UPDATE`, `MODIFY`, `DELETE`

The `INSERT`, `UPDATE`, `MODIFY`, and `DELETE` statements that change the data of database tables. Lesson [59](../course/0059-writing-to-the-database.md).
