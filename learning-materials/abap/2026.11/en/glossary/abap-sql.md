## ABAP SQL

The SQL dialect built into ABAP (formerly _Open SQL_): it reads and writes database tables independently of the underlying database. Lessons [52](../course/0052-select-basics.md), [97](../course/0097-modern-abap-sql.md), [98](../course/0098-advanced-abap-sql.md).

## Dynamic SQL

A `SELECT` whose table, fields, or conditions are strings decided at runtime. Lesson [117](../course/0117-dynamic-sql-and-calls.md).
