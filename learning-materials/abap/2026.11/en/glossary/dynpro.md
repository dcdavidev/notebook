## Dynpro

A classic SAP GUI screen, with its layout and flow logic (transaction SE51). Lesson [101](../course/0101-dynpro-basics.md).

## Flow logic

The code of a Dynpro that connects the screen to ABAP modules, split into PBO and PAI. Lesson [102](../course/0102-dynpro-flow-logic.md).

## PAI, PBO

The two phases of a Dynpro's flow logic: _Process Before Output_, before the screen is shown, and _Process After Input_, after the user acts. Lesson [102](../course/0102-dynpro-flow-logic.md).

## GUI status

The set of menus, buttons, and function keys of a screen, set with `SET PF-STATUS`. Lesson [104](../course/0104-gui-status-and-popups.md).

## Screen Painter

The tool (transaction SE51) for drawing a Dynpro's layout and writing its flow logic. Lesson [101](../course/0101-dynpro-basics.md).

## Module pool

A type M program that holds Dynpros and their modules, started by a transaction. Lesson [101](../course/0101-dynpro-basics.md).
