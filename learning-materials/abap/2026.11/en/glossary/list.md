## Classic list

A report's text output, written with `WRITE` and shown in SAP GUI page by page. Lessons [11](../course/0011-output-with-write.md), [67](../course/0067-interactive-lists.md).

## `WRITE`

The statement that prints text and values on a classic list. Lesson [11](../course/0011-output-with-write.md).

## Interactive list

A classic list where the user double-clicks a line to open a detail list (`AT LINE-SELECTION`). Lesson [67](../course/0067-interactive-lists.md).
