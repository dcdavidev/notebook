## Data object

An area of memory with a type that the program reads and changes: variables, constants, structures, internal tables. Lesson [12](../course/0012-variables-and-constants.md).

## Variable

A named data object, declared with `DATA`, whose value can change at runtime. Lesson [12](../course/0012-variables-and-constants.md).

## Constant

A data object with a fixed value, declared with `CONSTANTS`, that cannot change at runtime. Lesson [12](../course/0012-variables-and-constants.md).

## Literal

A value written directly in the code: text in quotes (`'ABC'`), a string in backquotes, or a number. Lesson [12](../course/0012-variables-and-constants.md).

## Inline declaration

Declaring a variable where it is first used, with `DATA(...)` or `FIELD-SYMBOL(...)`, with the type inferred from the context. Lesson [18](../course/0018-inline-declarations.md).
