## Application server

The layer of the SAP system that runs ABAP programs, between SAP GUI and the database; it also has its own file system. Lessons [3](../course/0003-sap-system-architecture.md), [74](../course/0074-files-on-the-application-server.md).

## Work process

An application server process that runs user requests: dialog, background, update, enqueue, spool. Lesson [3](../course/0003-sap-system-architecture.md).

## SAP instance

An application server started with its work processes; an SAP system can have several instances. Lesson [3](../course/0003-sap-system-architecture.md).
