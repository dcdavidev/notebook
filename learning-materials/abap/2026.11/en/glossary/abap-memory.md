## ABAP memory

The memory area shared by the programs of one session, written and read with `EXPORT ... TO MEMORY` and `IMPORT ... FROM MEMORY`. Lesson [72](../course/0072-calling-programs-and-memory.md).

## SAP memory

The memory area that lasts for the whole user logon, with the `SET PARAMETER` and `GET PARAMETER` parameters that prefill transaction fields. Lesson [72](../course/0072-calling-programs-and-memory.md).
