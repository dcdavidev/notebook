## ABAP Cloud

The development model that uses only released APIs and the restricted language version, for upgrade-safe extensions and a _clean core_. Lesson [148](../course/0148-abap-cloud.md).

## Clean core

The principle that extensions don't modify SAP standard code and use only released interfaces, so upgrades stay simple. Lesson [148](../course/0148-abap-cloud.md).

## Released API

A class, interface, or CDS view that SAP has declared stable and usable in ABAP Cloud: the only way to use standard code from a cloud extension. Lesson [148](../course/0148-abap-cloud.md).

## ABAP language version

The setting of an object that decides which statements and objects it can use: _Standard ABAP_, or _ABAP for Cloud Development_ with the restricted language. Lesson [148](../course/0148-abap-cloud.md).

## Tier model

The three-tier extensibility model of SAP S/4HANA: ABAP Cloud code, wrappers around unreleased APIs, and classic code. Lesson [148](../course/0148-abap-cloud.md).

## XCO library

The library of released classes (_Extension Components_) for working with development objects, strings, dates, and more in ABAP Cloud. Lesson [148](../course/0148-abap-cloud.md).
