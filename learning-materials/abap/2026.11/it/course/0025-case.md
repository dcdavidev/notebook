_Livello principiante_

Spesso confronti la stessa variabile con una lista di valori: se la compagnia è `LH` fai questo, se è `AZ` fai quello, se è `UA` fai altro ancora. Puoi scriverlo con [IF ed ELSEIF](./0024-if-and-logical-expressions.md), ma ripeti la variabile in ogni condizione. `CASE` dice la stessa cosa in modo più chiaro: nomini il valore una volta sola, poi elenchi i casi possibili.

## L'istruzione CASE

```abap
REPORT zcase_demo.

DATA lv_carrid TYPE s_carr_id VALUE 'AZ'.

CASE lv_carrid.
  WHEN 'LH'.
    WRITE / 'Lufthansa'.
  WHEN 'AZ'.
    WRITE / 'ITA Airways'.
  WHEN 'UA'.
    WRITE / 'United Airlines'.
  WHEN OTHERS.
    WRITE / 'Altra compagnia'.
ENDCASE.
```

- Dopo `CASE` c'è il valore da controllare, l'**operando**.
- Ogni `WHEN` elenca un valore. ABAP confronta l'operando con ogni `WHEN` dall'alto in basso, esegue il codice della **prima** corrispondenza e poi prosegue dopo `ENDCASE`.
- `WHEN OTHERS` viene eseguito quando nessun altro `WHEN` corrisponde. È facoltativo, ma se lo ometti e nessun valore corrisponde, non succede nulla.

> [!TIP]
> `CASE` è come lo smistamento di un ufficio postale: l'impiegato legge il CAP una volta sola e mette la lettera nella casella giusta. Le lettere con un CAP sconosciuto finiscono nella casella "altro".

## Più valori in un solo WHEN

Unisci i valori con `OR` quando portano allo stesso codice:

```abap
CASE lv_carrid.
  WHEN 'LH' OR 'AZ' OR 'AF'.
    WRITE / 'Compagnia europea'.
  WHEN 'UA' OR 'AA' OR 'DL'.
    WRITE / 'Compagnia statunitense'.
  WHEN OTHERS.
    WRITE / 'Altra regione'.
ENDCASE.
```

I valori dopo `WHEN` possono essere letterali, costanti o variabili. Le costanti rendono il codice più facile da leggere e da modificare:

```abap
CONSTANTS lc_status_open   TYPE c LENGTH 1 VALUE 'O'.
CONSTANTS lc_status_closed TYPE c LENGTH 1 VALUE 'C'.

DATA lv_status TYPE c LENGTH 1 VALUE 'C'.

CASE lv_status.
  WHEN lc_status_open.
    WRITE / 'Prenotazione aperta'.
  WHEN lc_status_closed.
    WRITE / 'Prenotazione chiusa'.
  WHEN OTHERS.
    WRITE / 'Stato sconosciuto'.
ENDCASE.
```

## CASE o IF?

`CASE` confronta solo con `=`. Appena ti serve qualcos'altro, usa `IF`.

| Situazione                                              | Usa    |
| ------------------------------------------------------- | ------ |
| una variabile confrontata con una lista di valori fissi | `CASE` |
| intervalli (`< 10`, `BETWEEN`), `IS INITIAL`, pattern   | `IF`   |
| condizioni su più variabili diverse                     | `IF`   |

```abap
DATA lv_seats_free TYPE i VALUE 3.

CASE lv_seats_free.
  WHEN 0.
    WRITE / 'Esaurito'.
  WHEN OTHERS.
    IF lv_seats_free < 5.          " un intervallo: si torna a IF
      WRITE / 'Ultimi posti'.
    ELSE.
      WRITE / 'Disponibile'.
    ENDIF.
ENDCASE.
```

> [!WARNING]
> Viene eseguito un solo ramo. Se due righe `WHEN` contengono lo stesso valore, la seconda non viene mai raggiunta, e il controllo di sintassi non sempre te lo segnala. Tieni distinti i valori di ogni `WHEN`.

> [!WARNING]
> Aggiungi sempre `WHEN OTHERS` quando un valore inatteso può essere un errore, e gestiscilo lì, per esempio con un messaggio. Un `CASE` silenzioso che salta i valori sconosciuti è una fonte comune di bug.

Quando ti serve un valore invece di un ramo di istruzioni, l'espressione `SWITCH` fa lo stesso lavoro dentro un'assegnazione; la vedrai in [COND e SWITCH](./0092-cond-and-switch.md). Per i tipi di oggetto esiste `CASE TYPE OF`, che trovi insieme a [Polimorfismo e casting](./0085-polymorphism-and-casting.md).

## Esercizio

> [!IMPORTANT]
>
> Una variabile `lv_class` contiene una classe di prenotazione: `F` (prima), `C` (business) o `Y` (economy).
>
> 1. Con `CASE`, stampa il nome della classe, e `Classe sconosciuta` per qualsiasi altro valore.
> 2. Imposta anche una variabile `lv_luggage` con la franchigia bagaglio: 40 kg per `F` e `C`, 23 kg per `Y`, 0 negli altri casi. Stampala.

### Soluzione

```abap
REPORT zcase_exercise.

DATA lv_class   TYPE c LENGTH 1 VALUE 'C'.
DATA lv_luggage TYPE i.

CASE lv_class.
  WHEN 'F'.
    WRITE / 'Prima classe'.
  WHEN 'C'.
    WRITE / 'Business class'.
  WHEN 'Y'.
    WRITE / 'Economy class'.
  WHEN OTHERS.
    WRITE / 'Classe sconosciuta'.
ENDCASE.

CASE lv_class.
  WHEN 'F' OR 'C'.
    lv_luggage = 40.
  WHEN 'Y'.
    lv_luggage = 23.
  WHEN OTHERS.
    lv_luggage = 0.
ENDCASE.

WRITE: / 'Bagaglio (kg):', lv_luggage.
```

> [!NOTE]
>
> - `CASE operando. WHEN valore. ... ENDCASE.` esegue il codice del primo `WHEN` uguale all'operando.
> - Unisci più valori con `OR` in un solo `WHEN`.
> - `WHEN OTHERS` raccoglie tutti i valori che nessun altro `WHEN` riconosce; usalo per gestire i valori inattesi.
> - `CASE` confronta solo con `=`: per intervalli, pattern o più variabili usa `IF`.
> - `SWITCH` è la forma espressione di `CASE`.
