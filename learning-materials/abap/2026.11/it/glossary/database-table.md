## Database table

Una tabella definita nel Dizionario e creata nel database (tabella trasparente), con campi, chiave e impostazioni tecniche. Lezione [46](../course/0046-database-tables.md).

## Transparent table

Una tabella del Dizionario che corrisponde a una tabella fisica nel database, con gli stessi campi. Lezione [46](../course/0046-database-tables.md).

## Table buffering

La copia di una tabella, o di parte di essa, nella memoria dell'application server, per leggere senza andare al database. Lezione [46](../course/0046-database-tables.md).

## `INSERT`, `UPDATE`, `MODIFY`, `DELETE`

Le istruzioni `INSERT`, `UPDATE`, `MODIFY` e `DELETE` che cambiano i dati delle tabelle del database. Lezione [59](../course/0059-writing-to-the-database.md).
