## Function module

Una procedura globale e riutilizzabile, con interfaccia ed eccezioni, che si chiama con `CALL FUNCTION`. Lezione [70](../course/0070-function-modules.md).

## Function group

Il programma che raccoglie moduli funzione correlati e i loro dati globali (transazione SE80 o SE37). Lezione [70](../course/0070-function-modules.md).

## Update function module

Un modulo funzione chiamato `IN UPDATE TASK`, che scrive nel database solo al `COMMIT WORK`, in un processo separato. Lezione [113](../course/0113-update-task.md).
