## ABAP Cloud

Il modello di sviluppo che usa solo API rilasciate e la versione ristretta del linguaggio, per estensioni compatibili con gli aggiornamenti e con il _clean core_. Lezione [148](../course/0148-abap-cloud.md).

## Clean core

Il principio per cui le estensioni non modificano lo standard SAP e usano solo interfacce rilasciate, così gli aggiornamenti restano semplici. Lezione [148](../course/0148-abap-cloud.md).

## Released API

Una classe, un'interfaccia o una vista CDS che SAP ha dichiarato stabile e utilizzabile in ABAP Cloud: è l'unico modo per usare lo standard da un'estensione cloud. Lezione [148](../course/0148-abap-cloud.md).

## ABAP language version

L'impostazione di un oggetto che decide quali istruzioni e oggetti può usare: _Standard ABAP_, oppure _ABAP for Cloud Development_ con il linguaggio ristretto. Lezione [148](../course/0148-abap-cloud.md).

## Tier model

Il modello a tre livelli dell'estensibilità in SAP S/4HANA: codice ABAP Cloud, involucri (_wrapper_) su API non rilasciate e codice classico. Lezione [148](../course/0148-abap-cloud.md).

## XCO library

La libreria di classi rilasciate (_Extension Components_) per lavorare con oggetti di sviluppo, stringhe, date e altro in ABAP Cloud. Lezione [148](../course/0148-abap-cloud.md).
