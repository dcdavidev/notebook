## Batch input

La tecnica che carica dati simulando l'inserimento a mano nelle schermate di una transazione (`CALL TRANSACTION`, SM35). Lezione [130](../course/0130-batch-input.md).

## `CALL TRANSACTION`

L'istruzione che avvia una transazione da un programma; con `USING` esegue subito le schermate di un batch input. Lezione [130](../course/0130-batch-input.md).

## Batch input session

Un insieme di transazioni da eseguire salvato nel sistema, che si elabora e si controlla con SM35. Lezione [130](../course/0130-batch-input.md).
