## Class

Il modello da cui si creano gli oggetti: definisce attributi, metodi ed eventi. Può essere locale (in un programma) o globale (nel repository). Lezioni [76](../course/0076-classes-and-objects.md), [87](../course/0087-global-classes.md).

## Abstract class

Una classe dichiarata `ABSTRACT` che non si può istanziare: serve solo come superclasse. Lezione [83](../course/0083-abstract-and-final.md).

## Final class

Una classe dichiarata `FINAL` da cui non si può ereditare. Lezione [83](../course/0083-abstract-and-final.md).

## Global class

Una classe salvata nel repository (transazione SE24 o ADT) che tutti i programmi possono usare. Lezione [87](../course/0087-global-classes.md).

## Local class

Una classe definita dentro un programma, visibile solo in quel programma. Lezione [76](../course/0076-classes-and-objects.md).

## Static component

Un attributo o metodo di classe (`CLASS-DATA`, `CLASS-METHODS`) condiviso da tutte le istanze, che si usa senza creare un oggetto. Lezione [81](../course/0081-static-components.md).
