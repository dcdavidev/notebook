## Application server

Il livello del sistema SAP che esegue i programmi ABAP, fra il SAP GUI e il database; ha anche un proprio file system. Lezioni [3](../course/0003-sap-system-architecture.md), [74](../course/0074-files-on-the-application-server.md).

## Work process

Un processo dell'application server che esegue le richieste degli utenti: dialog, background, update, enqueue, spool. Lezione [3](../course/0003-sap-system-architecture.md).

## SAP instance

Un application server avviato con i suoi work process; un sistema SAP può avere più istanze. Lezione [3](../course/0003-sap-system-architecture.md).
