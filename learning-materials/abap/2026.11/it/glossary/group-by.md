## `GROUP BY`

In SQL raggruppa le righe per calcolare aggregati; con `LOOP AT ... GROUP BY` raggruppa le righe di una tabella interna. Lezioni [56](../course/0056-aggregates-and-group-by.md), [95](../course/0095-grouping-internal-tables.md).

## `HAVING`

La condizione SQL che filtra i gruppi dopo il `GROUP BY`, in base ai valori aggregati. Lezione [56](../course/0056-aggregates-and-group-by.md).

## Aggregate function

Una funzione SQL che calcola un valore su un gruppo di righe: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Lezione [56](../course/0056-aggregates-and-group-by.md).
