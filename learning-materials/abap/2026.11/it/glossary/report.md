## Report

Un programma eseguibile (`REPORT`), di solito con una schermata di selezione e un output a lista o ALV. Lezioni [8](../course/0008-hello-world.md), [66](../course/0066-report-events.md).

## Report event

Un blocco eseguito dal runtime in un momento preciso di un report: `INITIALIZATION`, `AT SELECTION-SCREEN`, `START-OF-SELECTION` e altri. Lezione [66](../course/0066-report-events.md).
