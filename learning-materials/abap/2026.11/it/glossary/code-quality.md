## ATC (ABAP Test Cockpit)

Lo strumento che esegue i controlli statici sul codice: errori, prestazioni, sicurezza e regole di stile. Lezione [107](../course/0107-code-quality.md).

## Code Inspector (SCI)

Lo strumento che esegue controlli statici configurabili sul codice; i suoi controlli girano anche dentro l'ATC. Lezione [107](../course/0107-code-quality.md).
