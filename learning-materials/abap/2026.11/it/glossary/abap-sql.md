## ABAP SQL

Il dialetto SQL integrato in ABAP (un tempo _Open SQL_): legge e scrive le tabelle del database in modo indipendente dal database sottostante. Lezioni [52](../course/0052-select-basics.md), [97](../course/0097-modern-abap-sql.md), [98](../course/0098-advanced-abap-sql.md).

## Dynamic SQL

Una `SELECT` in cui tabella, campi o condizioni sono stringhe decise a runtime. Lezione [117](../course/0117-dynamic-sql-and-calls.md).
