## Object

Un'istanza di una classe, con i propri valori degli attributi, raggiungibile attraverso una variabile di riferimento. Lezione [76](../course/0076-classes-and-objects.md).

## Instance

Un oggetto concreto creato da una classe con `NEW` o `CREATE OBJECT`, con i propri valori degli attributi. Lezione [76](../course/0076-classes-and-objects.md).

## Reference variable

Una variabile `TYPE REF TO` una classe o interfaccia che punta a un oggetto; più variabili possono puntare allo stesso oggetto. Lezione [76](../course/0076-classes-and-objects.md).

## Garbage collector

Il meccanismo del runtime che libera la memoria degli oggetti a cui non punta più nessuna variabile di riferimento. Lezione [76](../course/0076-classes-and-objects.md).
