_Livello pro_

ABAP SQL e CDS coprono la maggior parte della logica sul database, ma SAP HANA offre di più: **SQLScript**, il suo linguaggio procedurale, con variabili, tabelle intermedie, cicli e funzioni che esistono solo in HANA. Una **ABAP Managed Database Procedure** (AMDP) ti permette di scrivere SQLScript dentro un metodo di una classe ABAP. Il sistema ABAP crea e aggiorna per te la procedura nel database, e tu la trasporti come qualsiasi altro codice ABAP.

L'AMDP è l'ultimo passo fra gli strumenti del [code pushdown](./0131-code-pushdown.it.md): usala solo quando ABAP SQL e CDS non bastano.

> [!TIP]
> Un'AMDP è come scrivere un biglietto nella lingua del posto e passarlo allo chef: il cameriere (ABAP) prende comunque l'ordine e porta il piatto, ma le istruzioni nel biglietto sono solo per la cucina, e solo quella cucina le capisce.

## Una classe AMDP

Una classe AMDP implementa l'interfaccia marcatore `IF_AMDP_MARKER_HDB`, e i suoi metodi AMDP si implementano con `BY DATABASE PROCEDURE`:

```abap
CLASS zcl_flight_amdp DEFINITION PUBLIC FINAL CREATE PUBLIC.
  PUBLIC SECTION.
    INTERFACES if_amdp_marker_hdb.

    TYPES: BEGIN OF ty_load,
             carrid    TYPE s_carr_id,
             flights   TYPE int8,
             occupied  TYPE int8,
             occupancy TYPE decfloat34,
           END OF ty_load,
           tt_load TYPE STANDARD TABLE OF ty_load WITH EMPTY KEY.

    METHODS get_load
      IMPORTING VALUE(iv_from) TYPE s_date
      EXPORTING VALUE(et_load) TYPE tt_load.
ENDCLASS.

CLASS zcl_flight_amdp IMPLEMENTATION.
  METHOD get_load BY DATABASE PROCEDURE FOR HDB LANGUAGE SQLSCRIPT
                  OPTIONS READ-ONLY
                  USING sflight.
    -- passo 1: voli del mandante corrente a partire dalla data indicata
    lt_flights = SELECT carrid, seatsmax, seatsocc
                   FROM sflight
                  WHERE mandt  = SESSION_CONTEXT('CLIENT')
                    AND fldate >= :iv_from;

    -- passo 2: aggrega la tabella intermedia
    et_load = SELECT carrid,
                     COUNT(*)      AS flights,
                     SUM(seatsocc) AS occupied,
                     ROUND(SUM(seatsocc) * 100.0 / NULLIF(SUM(seatsmax), 0), 2) AS occupancy
                FROM :lt_flights
               GROUP BY carrid
               ORDER BY carrid;
  ENDMETHOD.
ENDCLASS.
```

Che cosa notare:

- `BY DATABASE PROCEDURE FOR HDB LANGUAGE SQLSCRIPT` rende il corpo del metodo SQLScript. I commenti sono `--`, non `"`, e le istruzioni finiscono con un punto e virgola.
- `USING` elenca ogni tabella, vista e altra AMDP che il metodo legge. Ciò che non è elencato la procedura non lo conosce.
- `OPTIONS READ-ONLY` promette che il metodo non modifica dati.
- I parametri si passano **per valore**, tipizzati con tipi elementari o tipi tabella con colonne elementari. Dentro SQLScript li leggi con i due punti: `:iv_from`, `:lt_flights`.
- `lt_flights` è una **variabile tabella**: un risultato intermedio che HANA può ottimizzare insieme all'istruzione successiva.

## La gestione del mandante

> [!WARNING]
> SQLScript non sa nulla del mandante. Una `SELECT` su `SFLIGHT` senza condizione sul mandante restituisce le righe di **tutti** i mandanti. Filtra `mandt` da solo, con `SESSION_CONTEXT('CLIENT')` o con un parametro di import riempito con `sy-mandt`.

Quando un'AMDP legge CDS view entity invece di tabelle, usa `OPTIONS CDS SESSION CLIENT current`, così le viste applicano per te il mandante corrente.

## Chiamare e fare il debug

Da ABAP, un metodo AMDP si chiama come qualsiasi altro metodo:

```abap
NEW zcl_flight_amdp( )->get_load( EXPORTING iv_from = '20250101'
                                  IMPORTING et_load = DATA(lt_load) ).
cl_demo_output=>display( lt_load ).
```

La prima chiamata crea la procedura nel database; le chiamate successive la eseguono direttamente. Per il debug, metti un breakpoint dentro il corpo SQLScript in ADT: l'**AMDP debugger** si ferma lì e mostra le variabili scalari e le variabili tabella.

Le AMDP girano solo su SAP HANA. Se il tuo codice deve girare anche su altri database, controlla prima con `cl_abap_dbfeatures=>use_features( )` e la funzionalità `cl_abap_dbfeatures=>call_amdp_method`, e prevedi un'alternativa in ABAP SQL.

## Quando conviene un'AMDP

| Usa un'AMDP per                                                                   | Resta su ABAP SQL o CDS per                        |
| --------------------------------------------------------------------------------- | -------------------------------------------------- |
| logica in più passi con tabelle intermedie                                        | join, filtri, aggregati, `CASE`                    |
| funzioni specifiche di HANA (analisi del testo, predittive, grafi, serie di dati) | logica che deve girare anche su altri database     |
| l'implementazione di una [CDS table function](./0138-cds-table-functions.it.md)   | modelli di dati riutilizzabili per Fiori e analisi |

Il codice AMDP è più difficile da leggere, testare e mettere sotto debug rispetto ad ABAP SQL, e aggira il [controllo accessi CDS](./0136-cds-access-control.it.md). Aggira anche il buffer delle tabelle dell'application server.

## Esercizio

> [!IMPORTANT]
>
> 1. Crea `ZCL_FLIGHT_AMDP` con il metodo `get_load` ed eseguilo da un report o con `if_oo_adt_classrun`.
> 2. Togli la condizione sul mandante e confronta il risultato su un sistema con dati di volo in più di un mandante.
> 3. Scrivi la stessa query in ABAP SQL. Quale versione terresti?

### Soluzione

```abap
SELECT FROM sflight
  FIELDS carrid,
         COUNT( * )      AS flights,
         SUM( seatsocc ) AS occupied,
         division( SUM( seatsocc ) * 100, SUM( seatsmax ), 2 ) AS occupancy
  WHERE fldate >= '20250101'
  GROUP BY carrid
  ORDER BY carrid
  INTO TABLE @DATA(lt_load_sql).
```

Senza la condizione sul mandante, l'AMDP somma i voli di tutti i mandanti. Tieni la versione ABAP SQL: fa lo stesso lavoro, gestisce il mandante in automatico e gira su ogni database. Questa AMDP è solo un esercizio sulla sintassi.

> [!NOTE]
>
> - Un'AMDP è un metodo di classe scritto in SQLScript, gestito e trasportato dal sistema ABAP.
> - La classe implementa `IF_AMDP_MARKER_HDB`; il metodo usa `BY DATABASE PROCEDURE FOR HDB LANGUAGE SQLSCRIPT` ed elenca le sue sorgenti in `USING`.
> - I parametri si passano per valore; in SQLScript si leggono con i due punti.
> - Gestisci tu il mandante, per esempio con `SESSION_CONTEXT('CLIENT')`.
> - Usa un'AMDP solo quando ABAP SQL e CDS non riescono a esprimere la logica.
