# ABAP glossary

The terms used in the lessons of the ABAP courses, grouped by subject in the same order as the [v2 course](../course/v2/README.en.md). Within each subject the terms are in alphabetical order, with a short definition and a link to the lesson that explains them. ABAP keywords are written as `code`.

## Subjects

1. [The SAP system and the tools](./01-sap-system.en.md): architecture, landscape, clients, SAP GUI, ADT, packages, and transports (11 terms).
2. [Syntax and data types](./02-syntax-and-data-types.en.md): the language rules, variables, types, conversions, and strings (16 terms).
3. [Control flow and debugging](./03-control-flow-and-debugging.en.md): conditions, loops, the debugger, and runtime errors (10 terms).
4. [Structures and internal tables](./04-internal-tables.en.md): structures, internal tables, keys, field symbols, and references (10 terms).
5. [The ABAP Dictionary](./05-abap-dictionary.en.md): domains, data elements, tables, views, search helps, and locks (11 terms).
6. [ABAP SQL and the LUW](./06-abap-sql.en.md): reading and writing the database, and saving data consistently (16 terms).
7. [Reports, messages, and selection screens](./07-reports.en.md): messages, texts, selection screens, events, lists, and jobs (12 terms).
8. [Modularization, programs, and files](./08-modularization.en.md): includes, subroutines, function modules, BAPIs, memory, and files (6 terms).
9. [Object-oriented programming and exceptions](./09-object-oriented.en.md): classes, objects, inheritance, interfaces, events, and exceptions (20 terms).
10. [Modern ABAP](./10-modern-abap.en.md): constructor expressions, iterations, grouping, and regular expressions (9 terms).
11. [ALV and Dynpro](./11-alv-and-dynpro.en.md): ALV lists and the classic SAP GUI screens (5 terms).
12. [Tests, quality, and system techniques](./12-quality-and-system-techniques.en.md): tests, code checks, authorizations, logs, updates, and dynamic programming (13 terms).
13. [Enhancements and integration](./13-enhancements-and-integration.en.md): extending SAP standard code and exchanging data with other systems (15 terms).
14. [SAP HANA and CDS](./14-sap-hana-and-cds.en.md): code pushdown, CDS views, and AMDP (9 terms).
15. [RAP, ABAP Cloud, and beyond](./15-rap-and-abap-cloud.en.md): the RESTful Application Programming Model, ABAP Cloud, and advanced techniques (20 terms).
